# 템플릿

## 등록된 유형

### `minimal` - 기본

- 표지는 대표색 배경 위 실제 책 표지만 중앙에 둔다.
- 문구 카드는 Pretendard, 책 제목, 문구 번호, 직접 인용, 실제 챕터명, `@dtd.page`를 사용한다.
- PDF 쪽수와 전체 진행률은 표시하지 않는다.

### `signature`

- 표지는 `minimal`과 같은 실제 책 표지 구성을 사용한다.
- 문구 카드는 흰 배경, 원형 프로필, 표시 이름, 계정명, 직접 인용만으로 구성한다.
- Apple SD Gothic Neo의 고정 글꼴 크기와 측정된 레퍼런스 좌표를 사용한다.
- 문구는 고정 크기에서 최대 2줄인 완결 문장만 고른다.
- 챕터, PDF 쪽수, 진행률, 하단 브랜드를 포함한 푸터는 표시하지 않는다.
- 프로필은 `DTD_PROFILE_IMAGE` 또는 프로젝트 assets 폴더의 dtd-profile.png를 사용한다.

#### 언제 쓰는가

`signature`의 강렬함은 짧은 길이가 아니라 **책 고유의 관점이 한 문장만으로 서는가**로 판단한다. 아래 조건을 모두 만족하는 문구가 3개 이상일 때만 사용한다.

1. PDF에서 대조한 완결된 직접 인용이다. 문장을 만들기 위해 의역하거나 서로 다른 구절을 잇지 않는다.
2. 앞 문맥, 대명사의 대상, 별도 설명 없이도 의미가 선다.
3. 책이나 해당 챕터의 고유한 개념, 비유, 대조 또는 주장이 드러나 다른 자기계발서에도 붙을 법한 일반 문구와 구별된다.
4. 고정 글꼴 크기로 렌더했을 때 1-2줄에 들어간다.

단순한 격려, 상투적인 성공·실패 문장, 짧기만 한 문장은 제외한다. 조건을 통과한 문구가 3개 미만이거나 핵심 논지가 주변 문맥과 긴 설명에 의존하면 `minimal`을 사용한다.

## 선택과 비교

새 콘텐츠에는 사용자 config의 `CARD_NEWS_DEFAULT_TEMPLATE` 값을 `template` 필드에 명시한다. 기존 콘텐츠에 필드가 없으면 렌더러는 `minimal`로 해석한다.

```bash
.agents/skills/card-news/scripts/card-news.sh templates
.agents/skills/card-news/scripts/card-news.sh compare <content.json>
```

`compare` 결과는 프로젝트 `.work/design-tests/<post-id>/`에 생성하며 발행 산출물로 사용하지 않는다.

## 새 템플릿 추가

1. 설정된 프로젝트의 템플릿 렌더러에 cover 함수와 quote 함수를 추가한다.
2. `TEMPLATES` 레지스트리에 안정적인 소문자 ID 하나를 등록한다.
3. 템플릿의 글꼴, 프로필, 레이아웃 요구사항을 이 문서에 추가한다.
4. 1080x1350 표지와 길이가 다른 문구 3개를 렌더하는 대표 테스트를 추가한다.
5. `templates`, `compare`, 프로젝트 테스트를 실행해 목록과 출력이 일치하는지 확인한다.

동적 플러그인 로더나 템플릿별 설정 스키마는 만들지 않는다. 명시적 레지스트리는 추가 순서와 발행 결과를 추적하기 쉽다.
